# Memory snapshot

Manual copy of the project/reference memory saved to this machine's Claude
Code memory store (`~/.claude/projects/<hash>/memory/`) while working on this
repo's DDS sync pipeline, kept here so it travels with `git clone` to another
machine. This is a snapshot, not the live memory system — a Claude Code
session on another machine won't automatically treat these files as its own
memory; copy them into that machine's own memory directory for the
equivalent project if you want that. For anything actually load-bearing,
prefer [`../../docs/dds-contract-pipeline.md`](../../docs/dds-contract-pipeline.md)
and [`../../CLAUDE.md`](../../CLAUDE.md) instead, which *are* auto-loaded by
Claude Code in this repo regardless of machine.
